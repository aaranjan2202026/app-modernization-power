### 5.7 External Integration Flow

```mermaid
sequenceDiagram
    participant System as Internal System
    participant Queue as Message Queue
    participant Worker as Background Worker
    participant External as External API
    participant DB as Database
    
    System->>Queue: Publish Integration Event
    Queue->>Worker: Consume Event
    activate Worker
    
    Worker->>Worker: Validate Event Data
    Worker->>External: Call External API
    activate External
    
    alt Success
        External-->>Worker: Success Response
        Worker->>DB: Update Status
        Worker->>Queue: Publish Success Event
    else Failure
        External-->>Worker: Error Response
        Worker->>Worker: Check Retry Count
        alt Retries Remaining
            Worker->>Queue: Re-queue with Delay
        else Max Retries Reached
            Worker->>DB: Log Failure
            Worker->>Queue: Publish Failure Event
        end
    end
    
    deactivate External
    deactivate Worker
```
